# Τα κεφάλαια μιας εφαρμογής

Μια εφαρμογή φέρνει μαζί της το εγχειρίδιό της, ως αρχεία Markdown στον δικό της φάκελο. Το egwmanual τα βρίσκει, τα
δείχνει μόνο στους χρήστες της εφαρμογής και προσθέτει την επιλογή **Εγχειρίδιο** στο μενού της. Η εφαρμογή δεν
εξαρτάται γι' αυτό από το egwmanual. Μόνο τα κουμπιά Βοήθεια το χρειάζονται.

## 1. Πού μπαίνουν τα κεφάλαια

```
<app>/doc/manual/<lang>/<κεφάλαιο>.md
<app>/doc/manual/<lang>/images/<εικόνα>
```

- Ένας φάκελος ανά γλώσσα (`el`, `en`, `de` …). Η μετάφραση έχει το ίδιο όνομα αρχείου στον φάκελο της άλλης γλώσσας.
- Ονόματα κεφαλαίων: πεζά λατινικά γράμματα, ψηφία και παύλες, με αριθμό στην αρχή, για παράδειγμα
  `40-myapp-odigos-00-vasika`. Τα κεφάλαια εμφανίζονται με τη σειρά των ονομάτων τους.
- Με πρώτη γραμμή `<!-- parent: <κεφάλαιο> -->` το κεφάλαιο εμφανίζεται κάτω από ένα άλλο κεφάλαιο της εφαρμογής
  (υποκεφάλαιο). Δείτε [Δικά σας κεφάλαια](01-manual-custom-chapters.md#3-γράψιμο-ενός-κεφαλαίου).
- Τα ονόματα είναι κοινά για όλες τις εφαρμογές, γιατί τα κουμπιά Βοήθεια ανοίγουν κεφάλαιο με το όνομά του. Δώστε ένα
  πρόθεμα της εφαρμογής, ώστε καμία άλλη εφαρμογή να μη χρησιμοποιεί το ίδιο όνομα. Αν το χρησιμοποιούν δύο, ισχύει της
  πρώτης εφαρμογής με αλφαβητική σειρά.
- Τα κεφάλαια βρίσκονται από το επόμενο αίτημα. Δεν χρειάζεται καταχώριση ούτε καθαρισμός cache.

Ο φάκελος ανήκει στο αποθετήριο της εφαρμογής. Έτσι τα κεφάλαια διαβάζονται και στο GitHub. Οι άγκυρες των ενοτήτων
σχηματίζονται όπως στο GitHub, οπότε οι σύνδεσμοι λειτουργούν και στα δύο.

## 2. Τι μπορεί να περιέχει ένα κεφάλαιο

Ό,τι και τα δικά σας κεφάλαια (δείτε [Δικά σας κεφάλαια](01-manual-custom-chapters.md#3-γράψιμο-ενός-κεφαλαίου)) και
επιπλέον:

- εικόνες σε υποφακέλους του `images/` (για παράδειγμα `images/icons/`). Μια εικόνα μέσα στο `images/icons/`
  εμφανίζεται ως εικονίδιο μέσα στο κείμενο·
- εικόνες SVG (οι εικόνες της εφαρμογής θεωρούνται αξιόπιστες, του φακέλου των δικών σας κεφαλαίων όχι)·
- συνδέσμους σε κεφάλαια άλλων εφαρμογών. Όποιος δεν έχει την άλλη εφαρμογή βλέπει απλό κείμενο.

Σύνδεσμοι μέσα στο αποθετήριο (`../../doc/…`) εμφανίζονται ως απλό κείμενο στο παράθυρο του εγχειριδίου.

## 3. Το κουμπί Βοήθεια μιας οθόνης

Ένα κουμπί Βοήθεια ανοίγει ένα κεφάλαιο, προαιρετικά σε μια ενότητα. Σε ένα πρότυπο (template):

```xml
<et2-button-icon statustext="Open the user guide of this screen" label="Help" id="help" image="question-circle"
  noSubmit="true" onclick="egw.openPopup(egw.link('/index.php', {menuaction: 'egwmanual.EGroupware\\Egwmanual\\Ui.page',
  page: '40-myapp-odigos-00-vasika', anchor: '2-η-λίστα'}), 920, 850, 'egwmanual'); return false;"/>
```

Από PHP η `\EGroupware\Egwmanual\Manual::link($page, $anchor)` δίνει τη διεύθυνση (για παράδειγμα ως `help_url` στο
περιεχόμενο ενός προτύπου). Μη δίνετε γλώσσα. Το εγχειρίδιο ανοίγει τότε στη γλώσσα του χρήστη ή σε μια γλώσσα στην
οποία υπάρχει το κεφάλαιο.

## 4. Το κεφάλαιο που ανοίγει το μενού

Χωρίς άλλη ρύθμιση, η επιλογή **Εγχειρίδιο** (στο μενού της εφαρμογής, και στο μενού του χρήστη όταν η εφαρμογή είναι
μπροστά) ανοίγει το πρώτο κεφάλαιο της εφαρμογής. Για να ανοίγει άλλο, δηλώστε το
hook `manual_start` στο `setup/setup.inc.php` και επιστρέψτε το όνομα του κεφαλαίου:

```php
$setup_info['myapp']['hooks']['manual_start'] = 'EGroupware\\Myapp\\Hooks::manual_start';
```

```php
public static function manual_start($data = null)
{
	return '40-myapp-odigos-00-vasika';	// $data['lang']: η γλώσσα του εγχειριδίου
}
```

Ένα νέο hook χρειάζεται **Διαχειριστής › Clear cache/register hooks** (ή ενημέρωση της εφαρμογής).

## 5. Πίνακες από τις ρυθμίσεις της εφαρμογής

Ένα κεφάλαιο μπορεί να περιέχει μέρη που υπολογίζονται από την εγκατάσταση, για παράδειγμα τις καταστάσεις που όρισε
ο διαχειριστής:

```
<!-- live: myapp.statuses -->
Κείμενο που φαίνεται στο GitHub, και στο εγχειρίδιο όταν ο πίνακας δεν μπορεί να υπολογιστεί.
<!-- /live -->
```

Το egwmanual καλεί τότε τη `myapp_manual::block_statuses(string $lang, string ...$args)` (κλάση στο
`myapp/inc/class.myapp_manual.inc.php`). Λέξεις μετά το όνομα (`<!-- live: myapp.statuses open -->`) περνούν ως
ορίσματα. Επιτρέπονται μόνο γράμματα, ψηφία, `_` και `-`.

Κανόνες για μια τέτοια μέθοδο:

- Επιστρέφει Markdown, ή `''` για να εμφανιστεί το γραμμένο κείμενο. Και μια εξαίρεση (exception) εμφανίζει το γραμμένο
  κείμενο και καταγράφεται.
- Ό,τι επιστρέφει περνά από τον ίδιο έλεγχο με το υπόλοιπο κεφάλαιο. Επιστρέφετε Markdown, ποτέ HTML. Μια εικόνα
  επιστρέφεται ως `![…](data:image/svg+xml;base64,…)`.
- Για ονόματα με μεταφράσεις χρησιμοποιήστε τη `$lang`. Το παράθυρο τρέχει ως egwmanual: φορτώστε τις φράσεις της
  εφαρμογής με `Api\Translation::add_app('myapp')` πριν καλέσετε τη `lang()`.
- Η μέθοδος τρέχει με τα δικαιώματα του αναγνώστη και μόνο αν ο αναγνώστης έχει την εφαρμογή. Δείχνετε μόνο ό,τι
  επιτρέπεται να δει ο αναγνώστης αυτός.
